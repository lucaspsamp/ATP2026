Neste TPC5 foi desenvolvida uma aplicação em Python para gestão de alunos. A aplicação permite criar uma turma, inserir alunos, listar os alunos existentes, consultar alunos através do seu ID, guardar a turma num ficheiro e carregar uma turma previamente guardada. Durante a realização do trabalho foram utilizados conceitos como listas, tuplos, ciclos while e for, estruturas condicionais e manipulação de ficheiros.
