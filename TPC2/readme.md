Neste trabalho foi desenvolvido em Python o jogo "Adivinha o número."

O jogo tem duas modalidades:
- O computador pensa num número entre 0 e 100 e o utilizador tenta adivinhar.
- O utilizador pensa num número entre 0 e 100 e o computador tenta adivinhar.
 
Em ambas as modalidades são dadas indicações se o número é maior ou menor e, quando o número é descoberto, é apresentado o número de tentativas realizadas.
